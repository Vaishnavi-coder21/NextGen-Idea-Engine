# 🚀 NextGen IdeaEngine

**NextGen IdeaEngine** is a premium, AI-powered innovation platform designed for high-tier technical research and project discovery. It combines a futuristic glassmorphic UI with advanced NLP analytics to help users identify research gaps and generate novel technical blueprints.

---

## ✨ Features

### 🧠 AI Innovation Engine
*   **Semantic Matching**: Uses TF-IDF analysis to calculate the "Uniqueness Score" of project ideas.
*   **Blueprint Generation**: Automatically suggests cutting-edge algorithms (e.g., Transformer-XL, Zk-SNARKs) and tech stacks.
*   **Research Gap Analysis**: Identifies missing components in existing solutions to guide future development.

### 🔍 Smart Repository & Search
*   **Multi-Field Search**: Real-time discovery across titles, problem statements, algorithms, and technologies.
*   **Intelligent Suggestions**: A responsive autocomplete system that understands technical context.
*   **Elastic Filtering**: Instant filtering by technical domain, algorithm, and year.

### 📊 Live Analytics Dashboard
*   **Real-time Metrics**: Visualizes repository statistics using Chart.js.
*   **Growth Trends**: Tracks innovation scores and technical domain distribution over time.
*   **Algorithm Popularity**: Shows the most utilized technical architectures across the repository.

### 🔐 Secure Authentication
*   **Dual-Track Auth**: Supports robust email-based accounts and a seamless Google Sign-In simulation.
*   **Account Protection**: Integrated regex validation and a complete password recovery workflow.

---

## 🛠️ Tech Stack

### Frontend
- **Vanilla JS**: ES6+ modules for clean, performant logic.
- **Glassmorphic CSS**: Custom-built design system with HSL colors and vibrant gradients.
- **HTML5 Canvas**: Powers the interactive Neural Network particle background.
- **Chart.js**: High-performance data visualization.

### Backend
- **Node.js & Express**: Fast, minimal, and scalable API architecture.
- **Natural (NLP)**: Handles term frequency analysis for the innovation engine.
- **Custom NoSQL Mock DB**: A portable, file-based database system supporting complex query pipelines.

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v14 or higher)
- npm (Node Package Manager)

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/Vaishnavi-coder21/NextGen-Idea-Engine.git

# Install dependencies
npm install
```

### 3. Run the Server
```bash
# Start the backend server
node backend/server.js
```
The site will be available at: [**http://localhost:5000**](http://localhost:5000)
